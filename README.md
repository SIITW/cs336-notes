## 目录结构

每一讲的目录中都有一个 `README.md` 和该讲 Markdown 实际引用的教学图示（`assets/` 或 `figures/`）。当前主分支不放 PDF、视频、原始字幕、候选帧清单或制作审计文件，避免把读者阅读和制作过程混在一起。

课程主页：[cs336.stanford.edu](https://cs336.stanford.edu/)。课程内容与原始素材的版权归 Stanford、课程团队及相应作者所有；本仓库是个人学习整理，与 Stanford 无隶属关系。
